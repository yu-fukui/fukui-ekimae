    掲載依頼・情報の修正について

    お店の掲載・情報の修正は、こちらからご連絡ください。お店の方でなくても、閉店・移転などの情報をお寄せいただけると助かります。必要に応じて運営から折り返します。

    ご用件

    店舗会員になると、写真・紹介文・営業時間・予約ページなどをご自身で載せられます。お店の電話番号などでご本人確認をしたうえで、ログインのご案内をメールでお送りします。

    20歳未満の飲酒は法律で禁止されています。飲酒運転は絶対にやめましょう。
